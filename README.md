# Podcast Clipper Frontend

This is the frontend application built with Next.js for the Podcast Clipper project.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- Upload podcast videos
- Generate viral clips automatically
- Download clips with podcast titles
- Preview clips before downloading
